Tinted 12px-radius note for info, warnings and errors. Never use it for generated "AI" summaries; the product removed those.

```jsx
<Callout tone="info" eyebrow="Note">Trial ends within 48 hours.</Callout>
<Callout tone="error" title="Stripe returned an error">Most common cause: …</Callout>
```

Keep body to one or two plain sentences. Error copy states the fix, never apologises.
